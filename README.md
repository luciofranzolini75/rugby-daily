# Rugby Daily
Juego web instalable (PWA) para adivinar jugadores de rugby.
## Publicación
El sitio se publica en GitHub Pages desde la rama `main`, carpeta raíz.
## Instalación
- Android: abrir el sitio en Chrome y elegir "Instalar aplicación" o "Añadir a pantalla de inicio".
- iPhone: abrirlo en Safari, tocar Compartir y "Añadir a pantalla de inicio".
## Nota
El modo sin conexión guarda los archivos principales en caché. Algunas funciones en línea requieren conexión.
